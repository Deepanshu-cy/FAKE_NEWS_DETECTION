About This Project


Fake News Detection is a Machine Learning project developed to identify whether a news article is Real or Fake. This project uses Natural Language Processing (NLP) techniques to process the news text and classify it using a trained Machine Learning model.


Technologies Used


  • Python
  • Flask
  • HTML5
  • CSS3
  • JavaScript
  • Scikit-Learn
  • TF-IDF Vectorizer
  • Passive Aggressive Classifier

Project Objective


The objective of this project is to help users verify news articles by predicting whether they are genuine or fake. The system analyzes the text entered by the user and displays the prediction along with the confidence score.
